Configuration pour usage local :

1. Télécharger cette page :
• Clic droit → "Enregistrer sous" → ctf-map.html

2. Serveur HTTP local :
• Python: python -m http.server 8000
• Node.js: npx serve .
• Live Server (VS Code)

3. Configuration CTFd :
Ajoutez dans CTFd :
Access-Control-Allow-Origin: http://localhost:8000
